# Blinkit-Dashboard
🛒 Blinkit Sales Analysis Dashboard | Power BI

📌 Project Overview

This project focuses on analyzing Blinkit's sales performance using Power BI. The dashboard provides interactive visualizations and meaningful insights into sales, product categories, outlet locations, and customer preferences.

The objective is to transform raw sales data into actionable insights through data visualization and interactive reporting.

🎯 Project Objectives

- Analyze overall sales performance.
- Understand sales distribution across product categories.
- Compare outlet performance based on location and size.
- Identify customer preferences based on fat content.
- Explore trends and patterns using interactive visualizations.

🛠️ Tools & Technologies

- Power BI – Dashboard development and visualization
- Power Query – Data cleaning and transformation
- DAX – Calculated measures and KPIs
- Excel / CSV – Dataset handling

📊 Dashboard Features

1. Sales Performance Analysis

- Total Sales
- Average Sales
- Number of Items
- Average Rating

2. Product Analysis

- Sales by Item Type
- Sales by Fat Content
- Comparison of Low Fat and Regular products

3. Outlet Analysis

- Sales by Outlet Location
- Sales by Outlet Size
- Outlet Establishment Trends
- Outlet Type Performance

4. Interactive Filtering

Implemented dynamic slicers that allow users to filter dashboard data based on:

- Outlet Location
- Fat Content

These filters help users explore specific segments and analyze sales performance dynamically.

5. Visual Design

Designed a clean, professional dashboard inspired by Blinkit's brand identity, using a yellow and green colour palette for a consistent visual experience.

📈 Key Insights

The dashboard helps identify:

- Top-performing product categories.
- Sales contribution across different outlet locations.
- Differences in sales between Low Fat and Regular products.
- Outlet-level sales trends and performance.
